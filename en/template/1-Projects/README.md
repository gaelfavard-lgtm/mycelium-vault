# `1-Projects/` — what has a beginning and an end

Filter question: **"does it move a deliverable forward?"** A project = a folder = **one mandatory
note** (`project-<name>.md`) with a goal and a dated status. When the project is finished and the
user says so, the folder goes **as a single block** into `4-Archives/`.

A decided date is written in the name: `trip-april-2027`, `worksite-3-to-8-september-2026`;
a tentative date: `trip-april-2027-to-confirm`. Nothing settled: no date.

## Note template — the card at the top (40 lines base)

```markdown
# Project — <name>

## Card (≤ 40 lines)
**What it is for**: <one sentence>
**Guardrails**: <what must never be done on this project>
**Where we stand** (DD/MM): <the state, dated>
**Where to find what**: <links to the details>
— end of card —

## To clarify
## Details
## History
```

The AI reads the card up to "— end of card —" and only opens the details if the topic requires it.
