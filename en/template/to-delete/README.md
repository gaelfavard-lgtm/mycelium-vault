# `to-delete/` — the bin that only the human empties

**No AI deletes.** For an AI, deleting means moving here. The user re-reads and empties it
themselves. For a batch, a dated sub-folder (`YYYY-MM-DD-<reason>/`) with, if useful, a
one-line `WHY.md`.

*The name without spaces or special characters is a template choice: it avoids quoting trouble in
scripts. Rename it if you want, but then everywhere (`AGENTS.md`, scripts).*
