# `2-Casquettes/` — les responsabilités sans fin

Ce qu'on porte en continu : administratif, véhicules, santé, jardin, un métier… Question filtre :
**« est-ce que ça s'arrêtera un jour ? »** Non → casquette. Oui → projet.

Une casquette = un dossier = **une fiche de tête obligatoire** (`<nom>.md`, même nom que le
dossier). Sans elle, pas de wikilink depuis `MEMORY.md`, donc la casquette est invisible.
